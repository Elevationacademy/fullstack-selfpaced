# Intro

This short tutorial will walk you through the setup process of working with PostgreSQL.

  

  

To work with PostgreSQL, we first need to **connect to a server** that is hosting our database.

To do this, we'll install an extension in VS Code that allows us to connect with a local SQL server and execute SQL commands.

  

We'll be using the latest stable version of PostgreSQL. PostgreSQL has excellent compatibility with Node.js through the `pg` package, and its authentication mechanisms are well supported.
