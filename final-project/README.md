## Technical Requirements

Your project **MUST** incorporate the following technologies and concepts from the entire bootcamp:

- Client Side (React)
  - React Router
  - State Management
  - Mantine (or any other UI component library)
  - Responsive design that work on mobile and desktop
  - Error handling that is fully reflected in the 
- Server Side (Express)
  - Express MVC Architecture
  - Authentication & Authorization
  - Data Validation
  - Unified error handling
  - SQL or MongoDB
  - External storage for media files
- General
  - Deployment
  - External API Integration (or MCP)
  - AI Integration (very nice to have)


## Inspiration

We want to encourage you to create an innovative final project. Although CRUD operations should be part of your project, it is advisable that it won't be the main and only aspect of your application. Following are some ideas to give you some inspiration.

- **Memory Game Based on Google Photos.** Connect to Google Photos API to create a personalized memory matching game. Users can filter by location, date ranges, or detected people. Dynamic grid sizing adapts to screen size and difficulty level.
- **AI-Powered Travel Blog Generator.** Upload trip photos to auto-generate a chronological travel blog with map integration. AI extracts location data, suggests descriptions, and creates narrative flow. Users can edit and enhance the generated content.
- **Intelligent Code Review Bot.** GitHub integration that uses AI to analyze student code submissions. Identifies common patterns, suggests improvements, and generates class-wide feedback reports for instructors.
- **Smart WhatsApp Group Assistant.** AI bot that monitors group conversations, answers recurring questions, and maintains conversation context. Can schedule events, track shared expenses, or provide group analytics.

?> Usually, external integrations (APIs, AI, MCP), gives a boost of creativity and "superpowers" to our application

## Step 1: Team Formation

Assemble a team of 3 members and update the course TA.

It might make sense that internally you will define the following roles in your team (it's up to you):
- Product Lead - Focuses on UX/UI and product direction
- Client Lead - Focuses on client side decisions
- Server Lead - Focuses on server side decisions
- Integration Lead - Focuses on integrating with external systems (APIs, AI, etc.), integration of client and server and deployment

## Step 2: Product Document 

Create a comprehensive (**but short**!) product document that includes:
- Team members and roles
- Short product description
- Target users (guest is also a user)
- Main use cases per target user
- High level mockups for the main screens
- Navigation flow - How users move between screens
- DB Diagram (Table and Columns for SQL, JSON document for MongoDB)
- Server Endpoints
- APIs planning to use
- Extensions. Prepare a couple of extensions that you will implement only if time permits

_For mockups we encourage you to simply use a paper and pencil for manually drawing the screens and add it as an image to the document. But, if you insist (and have some spare time...), you are welcome to explore the following recommended tools for mockups [miro](https://miro.com/), [mockflow](https://mockflow.com/) or any other tool you feel comfortable with._

Please, make it short but clear!

Here is a [template](https://docs.google.com/document/d/1wTmyu4yT1ObzQqkKOUWbwSpF5uga_Lhfi4r85h2AKlg/edit?usp=sharing) for the document.
