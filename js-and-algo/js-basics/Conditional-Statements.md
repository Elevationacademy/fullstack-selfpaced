# Conditional Statements
In this lesson we're going to talk about basic control flow in JS. 


**Conditional Statements**:
-   `if`
-   `else if`
-   `else`

This is how it's done in  JS:
```js
if (x > 100){
  console.log("big")
} else if (x < 10) {
  console.log("small")
} else {
  console.log("x between 10 and 100")
}
```
