# React Module Hackathon Project

Welcome to the React Module Capstone Hackathon! This is your opportunity to showcase everything you've learned throughout the React module by building a real-world web application. You'll work in teams to create a full-featured application that demonstrates mastery of React concepts, state management, authentication, and modern web development practices.

## Technical Requirements

Your project **MUST** incorporate the following technologies and concepts from the React module:

- Forms (Controlled Components)
- React Router
- State Management
- Authentication & Authorization
- API Calls
- Supabase Backend
- Mantine (or any other UI component library)
- Responsive design that work on mobile and desktop
- Error handling that is reflected in the UI
- Loading indicators when data is fetched
- Publish app via Github Pages


## Step 1: Team Formation

#### Deadline: EOD Sunday, 17/8

Assemble a team of 3 members and update the course TA.

It might make sense that internally you will define the following roles in your team (it's up to you):
- Product Lead - Focuses on UX/UI and product direction
- Technical Lead - Focuses on architecture and complex features
- Quality Lead - Focuses on testing, code quality and meeting all technical requirements

## Step 2: Product Document 

#### Deadline: EOD Monday, 18/8

Create a comprehensive (**but short**!) product document that includes:
- Short product description
- Target users (guest is also a user)
- Main use cases per target user
- High level mockups for the main screens
- Navigation flow - How users move between screens
- DB plan for Supabase (tables and columns)
- APIs planning to use

_For mockups we encourage you to simply use a paper and pencil for manually drawing the screens and add it as an image to the document. But, if you insist (and have some spare time...), you are welcome to explore the following recommended tools for mockups [miro](https://miro.com/), [mockflow](https://mockflow.com/) or any other tool you feel comfortable with._

Please, make it short but clear!

## Step 3: Product Approval Meeting

#### Deadline: Tuesday, 19/8

Schedule a 15 minute meeting with the instructor and TA to present your proposal and get feedback. You should incorporate the feedback and send the final version of the document to the team.

## Step 4: Development Planning

#### Deadline: EOD Tuesday, 19/8

Create a detailed development plan using [Trello](https://trello.com/) (or equivalent project management tool). Send it to the TA for review and approval.

## Step 5 - Implementation Phase

#### Duration: Wednesday and Thursday, 20-21/8

Implement your product and have fun! 😎

## Step 6 - Demo Day

#### Sunday, 24/8

Suggested Demo Structure (10 - 15 min)
- Product overview and problem statement
- Live application demonstration
- Technical highlights and challenges
- Q&A from participants and team


## Evaluation 

You will receive live feedback from the team after your presentation. In our feedback we will focus on the following:

- Technical Implementation
- Product Quality (UX/UI)
- Demo Presentation
- Innovation & Creativity
